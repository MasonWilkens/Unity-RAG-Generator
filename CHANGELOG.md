# Changelog

## 0.1.0 — unreleased

This version remains an experimental, review-required local tool.

- Discover Unity source and serialized assets; map C# declarations, GUIDs,
  prefab references and supported overrides.
- Build maintained workspace generations with lexical, structured and optional
  local semantic retrieval, bounded source evidence and refresh recovery.
- Return literal source excerpts or optional model-generated draft explanations.
- Prepare wheel and source distributions with the bundled Roslyn analyzer,
  package metadata, a version command, isolated installation verification and CI.
- Freeze source-reviewed multi-project quality inputs before evaluation, compare
  rebuilt indexes against the same corpus, and retain per-category failure reports
  with explicit denominators and separate unmeasured answer-quality gates.
- Preserve CLI failure exit codes when launched with `python -m unity_rag`.
- Retain bounded literal YAML passages alongside parsed asset facts, with a
  separate keyword index and serialized-query companions that preserve existing
  scene/object anchors. Refresh adds this evidence to older workspaces.
- Treat complete identifier lookup requests as exact-name searches across search,
  semantic and hybrid modes; missing names no longer return shared word fragments.
- Select complementary source chunks for multipart code questions using declared
  types and parsed identifiers, including setter references, overloads and separate
  windows of long methods. Preserve citations, freshness checks and context limits.

Generated explanations require source review. Synthetic tests and development
benchmarks do not establish production answer quality. See the production plan
for the remaining release gates.
